# Security policy

Use the latest public release when possible. Security fixes are released as
soon as they pass review and CI.

Please report vulnerabilities privately through GitHub's private vulnerability
reporting feature for this repository. Open the repository's **Security** tab
and choose **Report a vulnerability**. Do not open a public issue for an
unfixed vulnerability. If private reporting is unavailable, contact the
maintainers through the GitHub organization profile and ask for a private
reporting channel.

Include the affected version, impact, and steps to reproduce. Avoid sending
credentials, personal data, or unrelated private project files.
